# 🎵 Python Song Player Project

A simple Python mini-project that plays audio files using the **playsound** library.
This project is perfect for beginners learning file handling and basic Python package usage.

## 🚀 Features

* Play any `.mp3` or `.wav` audio file
* Very simple and lightweight
* Uses the `playsound` package
* Works on Windows, macOS, and Linux

## 📦 Requirements

Install the required package:

```bash
pip install playsound
```

## ▶️ How to Run

1. Save your audio file (e.g., `song.mp3`)
2. Update the file path in the script
3. Run the Python file:

```bash
python song_player.py
```

## 📝 Sample Code

```python
import playsound

filename = "C:\\Users\\Abcom\\Downloads\\Thalapathy_Kacheri.mp3"
playsound.playsound(filename)
```
